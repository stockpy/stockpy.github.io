## 1. SAP Secure Login Service for SAP GUI

### 1.1 개요

SAP GUI 인터페이스에서 **다중 인증(MFA)**과 **싱글 사인온(SSO)**을 지원하는 **클라우드 기반(SaaS)** 인증 서비스입니다. SAP Single Sign-On 3.0의 공식 후속 제품이며, SAP BTP Cloud Foundry 환경에서 운영됩니다.

### 1.2 핵심 기능

- **다중 인증**: 비밀번호, TOTP, 로컬 X.509 인증서, Windows Hello, macOS Touch ID, FIDO 등
- **웹 브라우저 인증**: 임베디드/표준 웹 브라우저에서 인증 수행
- **단기 유효 사용자 인증서**: 인증 성공 시 SNC/SSF/TLS용 단기 인증서 자동 발급
- **구독자 웹 UI**: 관리용 SaaS 웹 인터페이스 제공
- **X.509 인증서 + Kerberos**: SNC 통신을 통한 AS ABAP 인증 지원

### 1.3 초기 설정 흐름

```
BTP 서브アカウント 권한 부여
    → SAP Cloud Identity Services 테넌트 설정
    → Secure Login Service 구독
    → OIDC / Custom CA 구성
    → Root CA 인증서 배포
    → Secure Login Client 설치 및 프로필 구성
    → AS ABAP에 SAP Cryptographic Library 설치
    → STRUST에 SAP Cloud Root CA import
    → SNC 파라미터 구성
```

### 1.4 지원 데이터센터

AWS(10개), Google Cloud(10개), Azure(10개), SAP(7개), Alibaba Cloud(1개) — Frankfurt, Tokyo, Seoul, Virginia 등 전역 커버

### 1.5 클라이언트 프로필 설정 주요 파라미터

| 파라미터 | 설명 |
|---|---|
| `pseType` | `browser`(임베디드), `standardbrowser`(macOS 표준 브라우저) |
| `enrollURL0` | SLS 인증 URL |
| `sncForceLogin` | SNC 핸드셰이크 전/후 인증서 제거 (0-3) |
| `allowBrowserSSO` | 브라우저 세션 재사용 (옵인) |
| `browserCacheHours` | 캐시 유지 시간 (1-48시간) |
| `autoEnroll` | 클라이언트 시작 시 자동 인증서 등록 |
| `mTLSIssuerNamePattern` | mTLS 인증서 필터링 |

### 1.6 SAP Single Sign-On 3.0 마이그레이션

**변경 사항:**

- **데스크톱**: Secure Login Client 버전 3.0 SP2 Patch 16 이상 필요 (동일 클라이언트 사용)
- **Secure Login Server(On-Premise)**: AS Java 인증 스택 제거, IAS 또는 기업 IdP로 대체, SLS CA로 교체, 클라이언트 프로필 업데이트
- **AS ABAP**: SAP Cloud Root CA를 STRUST에 import, 사용자 SNC 이름 업데이트
- **점진적 마이그레이션**: `GSSTargetName` 파라미터로 시스템별 인증 프로필 지정 가능

### 1.7 Custom CA 설정 (AWS Private CA)

| 설정 항목 | 설명 |
|---|---|
| Role ARN | Private CA 접근 권한 역할 |
| Private CA ARN | AWS Private CA 리소스 식별자 |
| Custom Subject Pattern | 인증서 주제 이름 패턴 |

인증서 주제 이름 패턴 예: `<CN=${sls_common_name}, OU=My Department, O=My Company, C=DE>`

### 1.8 SNC 로그인 옵션

스마트 카드 분실 등 SSO 자격 증명 없이 SNC 암호화 로그인 시 4가지 옵션:

1. **레거시 호환 모드**: CommonCryptoLib 8.5.x 이하 / SAPCRYPTOLIB 5.5.5
2. **스마트 모드**(권장): Secure Login Client가 최적 인증 방법 자동 선택
3. **영구 암호화 전용**: 전체 사용자/그룹 대상 롤아웃
4. **수동 전환**: 사용자가 "Toggle Encryption Only Mode"로 응급 모드 활성화

### 1.9 SAP Cryptographic Library 구성

트랜잭션 `SNCWIZARD`를 통해:

- SNC/SPNego 기본값 설정
- Kerberos keytab 생성
- X.509 자격 증명 관리
- SNC PSE 생성
- 적용을 위해 AS ABAP 인스턴스 재시작 필요

## 2. SAP Single Sign-On 3.0

### 2.1 개요

SAP 시스템에 대한 **비밀번호 없는 인증**을 위한 **온프레미스** 솔루션으로, 10년 이상 표준으로 사용되어 왔습니다. **2027년 말 유지보수 종료(EoM)** 예정입니다.

### 2.2 구성 요소

| 구성 요소 | 설명 |
|---|---|
| **Secure Login Server(SLS)** | 인증서 발급 및 인증 관리 서버 (AS Java 기반) |
| **Secure Login Client(SLC)** | 데스크톱 클라이언트 (Windows, macOS) |
| **Secure Login Web Client(SLWC)** | JavaScript 웹 기반 클라이언트 |
| **Secure Login Administration Console(SLAC)** | 관리 콘솔 |
| **Cryptographic Library** | SAPCRYPTOLIB / CommonCryptoLib |

### 2.3 인증 흐름

```
사용자 → Secure Login Client → Secure Login Server → X.509 인증서 발급
                                                    ↓
사용자 → SAP GUI (SNC) → AS ABAP/Java (X.509로 인증)
```

### 2.4 주요 특징

- **X.509 인증서 기반**: SAP 및 3사 웹 애플리케이션과 상호 운용 가능
- **2단계 인증 지원**: 스마트 카드, RSA 토큰 등
- **리스크 기반 인증**: 상황에 따른 인증 수준 조절
- **다양한 사용자 저장소**: LDAP, ABAP 등
- **SNC 암호화**: SAP GUI 및 RFC 클라이언트 네트워크 암호화
- **모바일 지원**: iOS, Android
- **SLS 없이 사용 가능**: 이미 인증서가 있는 경우 Secure Login Client만으로 운영 가능

## 3. Samsung SDS SingleID

### 3.1 개요

삼성SDS에서 제공하는 **클라우드 기반 통합 인증 및 계정 관리(IAM)** 솔루션입니다. 하이브리드 클라우드 환경에서 다양한 업무 시스템에 대한 단일 인증(SSO), 다중 인증(MFA), 계정 수명주기 관리를 제공하는 B2E/B2B/B2C용 IAM 서비스입니다.

### 3.2 핵심 구성 요소

| 구성 요소 | 설명 |
|---|---|
| **AM (Access Management)** | 단일 인증(SSO), SAML/OIDC 기반 접근 관리 |
| **IM (Identity Management)** | 사용자 계정 수명주기 관리 (생성/수정/삭제) |
| **MFA (Multi-Factor Authentication)** | 생체, PIN, TOTP, mOTP 기반 다중 인증 |
| **ADM (Anomaly Detection Management)** | 비정상 인증 활동 탐지 |
| **CAM (Cloud Access Management)** | 클라우드 콘솔/리소스 통합 접근 및 모니터링 |

### 3.3 지원 통합 대상

| 카테고리 | 예시 |
|---|---|
| **SaaS** | Microsoft 365, Google Workspace, Salesforce, Workday, Slack, ServiceNow, Atlassian, Dropbox |
| **On-Premise** | SAP, Oracle, 레거시 시스템 |
| **Mobile** | Microsoft, Google, Salesforce, Slack 모바일 앱 |
| **CSP** | AWS, Azure, Google Cloud, Samsung Cloud |

### 3.4 주요 기능

**SingleID Agent:**
- 브라우저 간 SSO 지원
- 보안 프로그램 미설치 시 PC 인증 차단
- 다중 브라우저 단일 로그아웃
- PC당 단일 사용자 로그인 지원

**SingleID Authenticator (모바일 앱):**
- iOS/Android 지원
- 생체 인증, PIN, TOTP, mOTP 방식 제공

**Zero Trust 보안 모델:**
- PDP(Policy Decision Point) 기반 상황 인식 인증
- 접속 환경/상황에 따른 조건부 접근 제어

**클라우드 접근 관리(CAM):**
- 클라우드 리소스 통합 접근
- 접근/운영 로그 모니터링 및 비정상 활동 탐지

### 3.5 이용 정보

- **무료 체험**: 30일 무료 트라이얼
- **결제 방식**: 사용자 수 기반 월정액
- **문의**: Samsung Cloud Platform → Security → SingleID

## 4. 비교 요약

| 항목 | SAP Secure Login Service | SAP Single Sign-On 3.0 | Samsung SDS SingleID |
|---|---|---|---|
| **유형** | 인증 서비스 (클라우드) | 인증 솔루션 (온프레미스) | IAM 플랫폼 (클라우드) |
| **배포** | BTP Cloud Foundry | AS Java (온프레미스) | Samsung Cloud Platform |
| **주요 대상** | SAP GUI 인증 | SAP 시스템 인증 | 전사 업무 시스템 |
| **MFA** | Windows Hello, Touch ID, FIDO 등 | 스마트 카드, RSA 토큰 | 생체, PIN, TOTP, mOTP |
| **SSO 범위** | SAP GUI 중심 | SAP 시스템 중심 | SaaS + On-Premise + 모바일 |
| **IdM** | ❌ | ❌ | ✅ 계정 수명주기 관리 |
| **비정상 탐지** | ❌ | ❌ | ✅ ADM |
| **클라우드 접근 관리** | ❌ | ❌ | ✅ CAM |
| **SAP 통합** | 네이티브 | 네이티브 | SAP 연동 가능 |
| **유지보수** | 활성화 중 | 2027년 말 EoM | 활성화 중 |
| **라이선스** | BTP 구독 | perpetual | 사용자 수 기반 월정액 |

### 4.1 선택 가이드

| 시나리오 | 권장 솔루션 |
|---|---|
| SAP GUI 인증만 필요, BTP 사용 중 | SAP Secure Login Service |
| SAP GUI 인증만 필요, 온프레미스 유지 | SAP Single Sign-On 3.0 (단, 2027년 이전 마이그레이션 필요) |
| 전사 시스템 통합 인증 및 계정 관리 필요 | Samsung SDS SingleID |
| SAP GUI + 전사 시스템 통합 | SAP Secure Login Service + Samsung SDS SingleID 병행 |
