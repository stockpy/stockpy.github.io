CASIO 시계 사용 설명서

* 모듈 번호: 2925
* 매뉴얼 번호: QW-2925
* 제조사: CASIO
* 공식 매뉴얼: CASIO Operation Guide 2925 (PDF)

1. 버튼 안내

버튼	주요 기능
A	설정 진입 및 화면 전환
B	시작, 정지, 값 감소 및 알람 설정 변경
C	모드 전환 및 설정 항목 이동
D	값 증가, 스톱워치 랩 기록, 초기화
L	조명 켜기

버튼의 기능은 현재 모드에 따라 달라집니다.

2. 모드 전환

C 버튼을 누르면 시계 모드가 순차적으로 변경됩니다.

모드	기능
Timekeeping	현재 시각 및 날짜
Stopwatch	스톱워치 및 랩 타임 측정
Recall	스톱워치 기록 조회 및 삭제
Countdown Timer	카운트다운 타이머
Alarm	알람 및 정시 알림
Dual Time	다른 시간대의 시각

모든 모드에서 L 버튼을 누르면 약 1초 동안 조명이 켜집니다.

3. 현재 시각 및 날짜 설정

설정 방법

1. Timekeeping 모드로 이동합니다.
2. A 버튼을 길게 눌러 초 표시가 깜박이게 합니다.
3. C 버튼으로 변경할 항목을 선택합니다.
4. D 버튼으로 값을 증가시키고 B 버튼으로 감소시킵니다.
5. 설정이 끝나면 A 버튼을 눌러 종료합니다.

설정 항목

항목	설정 방법
초	D 버튼을 누르면 00으로 초기화
시	D 증가 / B 감소
분	D 증가 / B 감소
12시간/24시간 표시	D 버튼으로 전환
연도	D 증가 / B 감소
월	D 증가 / B 감소
일	D 증가 / B 감소

참고 사항

* 12시간 표시에서는 오후에 P 표시가 나타납니다.
* 24시간 표시에서는 00:00부터 23:59까지 표시됩니다.
* 초가 30~59초일 때 00초로 초기화하면 분이 1 증가합니다.
* 초가 00~29초일 때는 분이 변경되지 않습니다.
* 연도 설정 범위는 2000~2039년입니다.
* 날짜와 요일은 자동으로 연동됩니다.
* 12시간/24시간 설정은 다른 모드에도 적용됩니다.

4. 스톱워치 (Stopwatch)

주요 기능

* 1/100초 단위 측정
* 경과 시간 측정
* 랩 타임 및 스플릿 타임 측정
* 운동 기록 저장
* 보폭과 페이서 설정을 이용한 거리 계산

4.1 경과 시간 측정

1. C 버튼으로 Stopwatch 모드에 진입합니다.
2. B 버튼을 눌러 측정을 시작합니다.
3. B 버튼을 다시 누르면 측정이 정지합니다.
4. 정지 상태에서 B 버튼을 누르면 측정이 재개됩니다.
5. 정지 상태에서 D 버튼을 누르면 표시가 0으로 초기화됩니다.

4.2 랩 타임 및 스플릿 타임

1. B 버튼을 눌러 측정을 시작합니다.
2. D 버튼을 누르면 현재 랩/스플릿 기록이 저장됩니다.
3. 기록 시간은 약 8초 동안 표시된 후 현재 측정 화면으로 돌아옵니다.
4. B 버튼으로 측정을 정지합니다.
5. D 버튼으로 표시를 초기화합니다.

용어 설명

* Lap Time: 한 바퀴 또는 특정 구간을 완료하는 데 걸린 시간
* Split Time: 출발부터 특정 지점까지 걸린 누적 시간

A 버튼을 누르면 랩 타임과 스플릿 타임의 표시 위치를 변경할 수 있습니다.

4.3 스톱워치 기록 저장

* 스톱워치 측정을 시작하면 새로운 로그가 생성됩니다.
* 랩/스플릿 기록은 메모리에 저장됩니다.
* 정지 후 D 버튼으로 0으로 초기화하면 해당 측정 로그가 종료됩니다.
* 저장된 기록은 Recall 모드에서 확인할 수 있습니다.
* 스톱워치 모드에서 다른 모드로 이동해도 측정은 계속됩니다.

4.4 기록 메모리

* 전체 메모리 용량은 로그 제목 화면을 포함하여 최대 61개 레코드입니다.
* 로그가 많을수록 저장 가능한 랩/스플릿 기록 수가 감소합니다.
* 메모리가 가득 차면 가장 오래된 로그 또는 기록이 자동 삭제될 수 있습니다.
* 누적 거리는 별도로 관리되며 로그 삭제만으로 초기화되지 않습니다.

5. 페이서 및 보폭 설정

이 기능은 달리기나 조깅 시 일정한 속도를 유지하고 이동 거리를 계산하기 위한 기능입니다.

5.1 설정 진입

1. Stopwatch 모드에서 측정 화면이 모두 0인지 확인합니다.
2. A 버튼을 길게 눌러 페이서 값이 깜박이게 합니다.
3. C 버튼으로 설정 항목을 이동합니다.
4. D/B 버튼으로 값을 변경합니다.
5. A 버튼을 눌러 설정을 종료합니다.

5.2 설정 항목

항목	설정 범위 및 기능
Pacer Value	분당 100~200회, 5회 단위
Pacer Signal	ON / OFF
Stride Length	40~190cm, 5cm 단위
Stride Length Unit	cm 또는 inch

페이서 값을 xxx로 설정하면 페이서 기능이 비활성화되며 거리 계산도 수행되지 않습니다.

5.3 보폭 단위와 거리 표시

보폭 단위	거리 단위
cm	km
inch	mile

보폭은 실제 운동 시 측정한 값을 사용하는 것이 좋습니다.

예를 들어 300m 트랙을 239걸음으로 달렸다면 다음과 같이 계산합니다.

* 300m ÷ 239걸음 ≈ 1.255m
* 설정 보폭은 약 125cm입니다.

5.4 페이서 신호 ON/OFF

1. Stopwatch 화면이 모두 0인지 확인합니다.
2. A 버튼을 길게 눌러 설정 화면으로 진입합니다.
3. C 버튼을 한 번 눌러 페이서 신호 항목을 선택합니다.
4. D 버튼으로 ON/OFF를 변경합니다.
5. A 버튼을 눌러 종료합니다.

페이서 신호가 켜져 있으면 설정한 분당 횟수에 따라 소리가 납니다.

6. 스톱워치 기록 조회 및 삭제 (Recall)

6.1 기록 조회

1. C 버튼으로 Recall 모드에 진입합니다.
2. A 버튼으로 로그 제목 화면을 이동합니다. 최신 로그가 먼저 표시됩니다.
3. 조회할 로그를 선택합니다.
4. D/B 버튼으로 해당 로그의 기록을 확인합니다.

조회할 수 있는 정보는 다음과 같습니다.

* 로그 번호 및 생성 날짜
* 기록된 랩/스플릿 시간
* 최고 랩 타임 표시
* 운동 거리
* 누적 거리

6.2 개별 로그 삭제

1. Recall 모드에서 삭제할 로그의 제목 화면을 표시합니다.
2. B와 D 버튼을 동시에 길게 누릅니다.
3. 시계에서 소리가 나고 CLR 표시가 사라질 때까지 기다립니다.

선택한 로그와 그 안의 기록이 모두 삭제됩니다.

주의: 삭제한 로그는 복구할 수 없습니다. 로그 삭제만으로 누적 거리가 초기화되지는 않습니다.

6.3 누적 거리 초기화

1. Recall 모드에서 누적 거리 화면을 표시합니다.
2. B와 D 버튼을 동시에 길게 누릅니다.
3. 시계에서 소리가 나고 CLR 표시가 사라질 때까지 기다립니다.

누적 거리만 0으로 초기화되며 기존 로그와 기록은 유지됩니다.

보폭 단위를 변경할 때는 먼저 누적 거리를 0으로 초기화해야 합니다.

7. 카운트다운 타이머 (Countdown Timer)

주요 기능

* 설정 범위: 1분~100시간
* 카운트다운 종료 시 알람
* 자동 반복 기능 지원

7.1 시작 시간 설정

1. C 버튼으로 Countdown Timer 모드에 진입합니다.
2. 시작 시간이 표시되는지 확인합니다.
3. A 버튼을 길게 눌러 시간 설정을 시작합니다.
4. C 버튼으로 시/분 항목을 선택합니다.
5. D 버튼으로 값을 증가시키고 B 버튼으로 감소시킵니다.
6. A 버튼을 눌러 설정을 종료합니다.

100시간을 설정하려면 시작 시간을 0:00으로 설정합니다.

7.2 타이머 사용

동작	버튼
시작	B
일시 정지	B
정지 상태에서 재개	B
시작 시간으로 초기화	정지 상태에서 D

카운트다운이 종료되면 자동 반복이 꺼져 있는 경우 알람이 약 10초 동안 울립니다. 아무 버튼이나 누르면 알람을 멈출 수 있습니다.

7.3 자동 반복 ON/OFF

1. Countdown Timer 모드에서 시작 시간이 표시되게 합니다.
2. D 버튼을 약 2초간 길게 누릅니다.
3. 자동 반복 표시가 나타나면 ON, 사라지면 OFF입니다.

자동 반복이 켜져 있으면 카운트다운이 0에 도달할 때마다 알람이 울리고 다시 시작합니다. 자동 반복은 최대 7회까지 진행됩니다.

8. 알람 (Alarm)

주요 기능

* 독립적인 일일 알람 5개
* Alarm 1의 스누즈 기능
* 정시 알림 기능

8.1 알람 시간 설정

1. C 버튼으로 Alarm 모드에 진입합니다.
2. D 버튼으로 알람 1~5 중 원하는 알람을 선택합니다.
3. A 버튼을 길게 눌러 시각 설정을 시작합니다.
4. C 버튼으로 시/분 항목을 선택합니다.
5. D/B 버튼으로 값을 변경합니다.
6. A 버튼을 눌러 설정을 종료합니다.

12시간 표시를 사용하는 경우 오전/오후가 올바른지 확인합니다.

8.2 알람 ON/OFF

* Alarm 2~5: 원하는 알람을 선택한 뒤 B 버튼으로 ON/OFF를 전환합니다.
* Alarm 1: B 버튼을 누를 때마다 다음 상태로 전환됩니다.

상태	기능
One-time Alarm	일반 알람 ON
Snooze Alarm	스누즈 알람 ON
Alarm Off	알람 OFF

8.3 스누즈 기능

* 스누즈 알람은 5분 간격으로 반복됩니다.
* 최대 7회 울립니다.
* 각 알람은 약 10초 동안 울립니다.
* 아무 버튼이나 누르면 현재 울리는 알람을 멈출 수 있습니다.
* 스누즈 알람 사이에 Timekeeping 설정 화면이나 Alarm 1 설정 화면을 표시하면 스누즈 동작이 취소될 수 있습니다.

8.4 알람 테스트

Alarm 모드에서 D 버튼을 길게 누르면 알람 소리를 테스트할 수 있습니다.

8.5 정시 알림 (Hourly Time Signal)

매시간 정각에 두 번의 소리가 나도록 설정할 수 있습니다.

1. Alarm 모드로 이동합니다.
2. D 버튼으로 :00 화면을 선택합니다.
3. B 버튼으로 ON/OFF를 전환합니다.

9. 듀얼 타임 (Dual Time)

다른 시간대의 시각을 확인할 수 있는 기능입니다.

설정 방법

1. C 버튼으로 Dual Time 모드에 진입합니다.
2. D 버튼으로 시간을 증가시킵니다.
3. B 버튼으로 시간을 감소시킵니다.
4. A 버튼을 누르면 현재 시각과 같은 시간으로 설정됩니다.

D/B 버튼을 한 번 누를 때마다 30분 단위로 변경됩니다.

듀얼 타임의 초는 기본 시각 모드의 초와 동기화됩니다.

10. 조명 및 자동 조명 (Illumination)

10.1 수동 조명

어느 모드에서든 L 버튼을 누르면 약 1초 동안 화면 조명이 켜집니다.

10.2 자동 조명 ON/OFF

1. Timekeeping 모드로 이동합니다.
2. D 버튼을 약 2초간 길게 누릅니다.
3. 자동 조명 표시가 나타나면 ON, 사라지면 OFF입니다.

자동 조명 기능은 약 6시간 후 배터리 절약을 위해 자동으로 꺼집니다.

10.3 자동 조명 작동 조건

1. 손목을 지면과 평행하게 합니다.
2. 시계를 얼굴 쪽으로 40도 이상 기울입니다.
3. 자동 조명이 켜집니다.

시계는 손목 바깥쪽에 착용하는 것이 좋습니다.

10.4 주의 사항

* 직사광선 아래에서는 조명이 잘 보이지 않을 수 있습니다.
* 알람이 울릴 때 조명은 자동으로 꺼집니다.
* 조명을 자주 사용하면 배터리 소모가 증가합니다.
* 손목 움직임이나 진동으로 자동 조명이 반복 작동할 수 있습니다.
* 자동 조명은 손등이 지면과 평행한 상태에서 작동하도록 해야 합니다.
* 시계가 평행 위치에서 위아래로 15도 이상 기울어져 있으면 조명이 작동하지 않을 수 있습니다.
* 자동 조명으로 인해 주의가 분산될 수 있으므로 자전거, 오토바이 및 자동차 운전 중에는 자동 조명을 꺼 두십시오.

11. 기타 동작 및 주의 사항

11.1 설정 화면 자동 종료

설정 화면에서 아무 조작 없이 약 2~3분이 지나면 설정 화면이 자동으로 종료됩니다.

11.2 값 빠르게 변경하기

B 또는 D 버튼을 길게 누르면 대부분의 설정 화면에서 값을 빠르게 변경할 수 있습니다.

11.3 날짜 및 달력

내장된 자동 달력은 월별 날짜 수와 윤년을 반영합니다. 날짜를 정확히 설정하면 배터리 교체 등 특별한 경우를 제외하고는 자주 변경할 필요가 없습니다.

11.4 메모리 관리

스톱워치 메모리가 가득 차면 가장 오래된 로그 또는 기록이 자동으로 삭제될 수 있습니다. 중요한 기록은 메모리 용량에 유의하여 관리하십시오.
