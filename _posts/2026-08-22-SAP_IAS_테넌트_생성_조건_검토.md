# SAP IAS 테넌트 생성 조건 검토 결과

## 1. IAS 테넌트 유형 및 BTP 계정 필요 여부

| 유형 | 설명 | BTP 계정 필요 여부 |
|---|---|---|
| **Bundle Tenant** | SAP 클라우드 솔루션(SuccessFactors 등)과 번들로 제공 | 해당 솔루션 구독 시 자동 포함 |
| **Standalone Tenant** | 별도 제품으로 제공 | ⚠️ **2020년 10월 20일 이후 신규 판매 중단** |
| **BTP Subaccount 기반** | BTP subaccount에서 Cloud Identity Services 인스턴스 생성 | **BTP Global Account 필요** |

## 2. 현재 IAS 테넌트 획득 경로

1. **BTP Global Account + Subaccount 필요**
   - BTP Cockpit → Subaccount → Entitlements에 "Cloud Identity Services" 추가
   - Services → Instances and Subscriptions → `default` 플랜으로 인스턴스 생성
   - 프로비저닝 후 IAS Admin Console에 접근
   - **무료 제공**: 각 BTP Global Account당 **production 1개 + test 1개** 무료
2. **번들 포함**: SuccessFactors 등 SAP 클라우드 솔루션 구독 시 IAS 포함
3. **SAP Support Case (KBA 2717185)**: 기존 SAP 계약이 있는 경우 추가 테넌트 요청 가능

## 3. 결론

현재 SAP에서 제공하는 IAS 테넌트 획득 경로는 모두 **BTP 계정** 또는 **SAP 클라우드 솔루션 구독**을 전제로 합니다.  
BTP 계정 없이 `accounts.ondemand.com` 테넌트를 직접 생성하는 경로는 존재하지 않습니다.

**즉, IAS를 사용하려면 다음 중 하나가 필요합니다:**
1. **SAP BTP Global Account** (CPEA 또는 Pay-As-You-Go)
2. **IAS를 번들하는 SAP 클라우드 솔루션 구독** (SuccessFactors 등)
