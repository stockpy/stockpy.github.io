# Jekyll 블로그 운영 가이드

## 1. 새 포스트 추가

**파일 생성** — `_posts/` 디렉토리에 `YYYY-MM-DD-제목.md` 형식으로 파일 생성:

```
_posts/2026-09-10-SAP_BTP_Subaccount_생성_가이드.md
```

**필수 형식** — 첫 줄에 front matter 포함:

```markdown
---
layout: post
title: 문서 제목
categories: 카테고리-슬러그
---

# 문서 제목

본문 내용...
```

**`categories` 필드**에 기존 카테고리 슬러그 중 하나를 입력하면 자동으로 해당 카테고리에 표시됩니다. 추가 작업 불필요.

---

## 2. 카테고리 목록

| 슬러그 | 라벨 | 설명 |
|---|---|---|
| `sso-auth` | SSO / 인증 | SSO, 인증, MFA |
| `identity` | Identity / IdP | IAS, Corporate IdP, 신뢰 설정 |
| `btp` | BTP / 플랫폼 | BTP, Object Store, Private Link |
| `monitoring` | 모니터링 / 알림 | Alert Notification, Events |
| `sapgui` | SAP GUI | SAP GUI, WebGUI, SLS |
| `general` | 기타 | 위 외 기타 |

---

## 3. 새 카테고리 추가 (3단계)

**① `_data/category_labels.yml`**에 라벨 추가:

```yaml
새-슬러그: "카테고리 라벨"
```

**② `categories/` 디렉토리에 `{슬러그}.html` 생성:**

```html
---
layout: default
permalink: /categories/새-슬러그.html
categories: 새-슬러그
---
<div class="category-header">
  <h1>카테고리 라벨</h1>
  <p>카테고리 설명</p>
</div>
<ul class="post-list">
  {% for post in site.categories.새-슬러그 %}
  <li>
    <a href="{{ post.url | relative_url }}" class="post-title">{{ post.title }}</a>
    <div class="post-date">{{ post.date | date: "%Y-%m-%d" }}</div>
  </li>
  {% endfor %}
</ul>
```

**③ `_config.yml`**의 `categories` 목록에 추가:

```yaml
categories:
  - sso-auth
  - identity
  - btp
  - monitoring
  - sapgui
  - general
  - 새-슬러그
```

---

## 4. 카테고리 라벨/설명 수정

| 수정 대상 | 파일 위치 |
|---|---|
| 라벨(네비게이션 표시명) | `_data/category_labels.yml` |
| 설명(카테고리 페이지 하단) | `categories/{슬러그}.html`의 `<p>` 태그 |

---

## 5. 요약

| 작업 | 할 것 |
|---|---|
| 새 포스트 추가 | `_posts/`에 `YYYY-MM-DD-제목.md` 생성, `categories` 필드만 입력 |
| 카테고리 변경 | 포스트 front matter의 `categories` 값 수정 |
| 새 카테고리 | 라벨 파일 + 카테고리 페이지 + config 3곳 수정 |
| 라벨 수정 | `_data/category_labels.yml`만 수정 |
