# SAP Certified Solutions Directory — 등록 제품 vs 미등록 제품

## 등록 제품 (Certified Solutions)의 특징

| 항목 | 내용 |
|---|---|
| **기술 검증** | SAP 팀이 직접 엄격한 통합 테스트를 수행하고 통과해야 함 |
| **호환성 보장** | SAP 기술 인프라, 보안 규칙, 비즈니스 규칙과 호환됨 |
| **지속적 유지 요구** | 인증 유지를 위해 지속적인 요건 충족 필요 |
| **SAP 지원 연계** | 인증된 솔루션 관련 이슈 시 SAP 지원 경로 활용 가능 |
| **인증 로고 사용** | SAP Certified Integration 로고 및 S/4HANA 로고 등 마케팅 사용 가능 |
| **SAP.com 노출** | sap.com 온라인 디렉토리에 등재되어 고객 노출 |
| **SAP 이벤트 출품** | Sapphire, TechEd 등 SAP 행사에서 제품 전시 가능 |

## 미등록 제품 (Non-Certified Solutions)의 리스크

| 리스크 | 설명 |
|---|---|
| **성능 저하** | SAP 시스템과의 통합 시 성능 저하 가능성 |
| **신뢰성 감소** | 시스템 안정성 보장 불가 |
| **보안 취약** | SAP 보안 규칙 준수 여부 검증되지 않음 |
| **업그레이드 충돌** | S/4HANA 업그레이드 시 서드파티 소프트웨어와 충돌 가능 |
| **지원 불가** | SAP 기술 지원에서 미인증 솔루션 관련 이슈에 대한 지원 제한 |
| **구현 시간 증가** | 통합 비용 및 구현 기간 증가 |
| **Private Cloud Edition 사용 불가** | S/4HANA PCE 등 특정 클라우드 옵션에서 인증된 솔루션만 허용 |

## 근거

### 기술 검증

> Once the testing is concluded successfully, you will receive a detailed and confidential test report, a certificate, and the appropriate certification logo.

— [SAP Partners — Certify My Solution](https://www.sap.com/partners/partner-program/certify-my-solution.html)

### 호환성 보장

> To be SAP Certified, a partner solution must prove interoperability with SAP applications following SAP technical best practices and guidelines. Selecting a certified partner solution helps ensure that you can cut implementation times, lower integration costs, and be confident of compatibility with your SAP technology infrastructure.

— [SAP Store FAQ](https://www.sap.com/store/faq.html)

### 지속적 유지 요구

> Software integration certifications are valid for **three years** for most integration scenarios. Certification scenarios for integrations for cloud and SAP HANA are valid for **only one year**, due to a high frequency of updates.

— [SAP Partners — Certify My Solution](https://www.sap.com/partners/partner-program/certify-my-solution.html)

> Having this Certified SAP Integration means that the software not only meets SAP's minimum requirements, but that it has also passed rigorous tests performed by the SAP team, **including a requirement to continue to fulfil the necessary ongoing requirements to maintain that certification.**

— [EPI-USE Labs — SAP Certified Partner vs SAP Certified Solution](https://www.epiuselabs.com/lets-talk-hcm/what-is-the-difference-sap-certified-partner-sap-store-listing-and-sap-certified-solution)

> SAP ICC 인증 프로그램이 개편되었으며, 파트너 솔루션은 새로운 인증 프레임워크에 따라 유효 기간 내에 재인증해야 합니다.

— [Updates to SAP's Integration Certification Program — SAP News Center](https://news.sap.com/2026/01/updates-sap-integration-certification-program-partner-built-solutions)
