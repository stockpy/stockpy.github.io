# SAP Note 3659006 — SAP GUI for HTML (WebGUI) 핵심 제한 사항 요약

## 개요
SAP GUI for HTML (WebGUI)가 네이티브 SAP GUI for Windows 대비 지원하지 않는 기능과 제한 사항을 정리한 문서입니다.

---

## 핵심 제한 사항

| 영역 | 제한 내용 |
|---|---|
| **IMC (Inter Mode Communication)** | HTTP 세션에서 미지원 |
| **Microsoft RemoteApp** | 미지원 |
| **프론트엔드 프린팅** | PDF 기반 출력만 가능 (Note 771683) |
| **Business Graphics** | IGS 기반 표시만 가능, 인터랙티브 그래픽 미지원 |
| **OLE Automation** | 불가능 |
| **Office Integration** | 읽기 전용, 수정 불가 (Note 3386113) |
| **스크롤 위치 유지** | 미지원 |
| **키보드 네비게이션** | 화살표 키로 입력 필드 이동 불가 (ALV/TableControl 제외) |
| **Tree Control** | 키스트로크 이벤트, 드래그 앤 드롭 열 교환 미지원 |
| **TextEdit Control** | 워드랩 제한, 보호 텍스트 영역 미지원 |
| **ALV Grid** | 마우스 범위 선택 불가, Excel 내보내기 제한, 셀 병합 불가 |
| **StepLoop 스크롤** | 마우스 휠/PageUp/PageDown 미지원 |
| **ABAP List 스크롤** | 백엔드 정적 페이지로 인해 스크롤 경험 제한 |
| **HTML Control** | 제한적 지원 (Note 3024355) |
| **Dropdown Listbox** | TableControl/ALV Grid에서 닫힌 상태에서 첫 글자 네비게이션 불가 |
| **Dialog Box Container** | WebGUI는 모달, SAP GUI for Windows는 모달이 아님 |
| **Negative Values (ALV)** | 마이너스가 값 뒤에 표시될 때 소수점 정렬 불일치 |

## SAP S/4HANA 사용 시 영향 분석

### 고위험 (비즈니스 작업 직접 차단)

| 제한 | S/4HANA 영향 시나리오 |
|---|---|
| **Office Integration — 읽기 전용** | LS2X/LC27 등 Excel 기반 분석이 수정 불가. SE16N에서 Excel 내보내기 후 수정 작업 불가 |
| **ALV Grid — 마우스 범위 선택 불가** | FB03 등 문서 조회 시 다중 선택이 Ctrl/Shift 필수. 대량 데이터 복사·비교 작업 저하 |
| **ALV Grid — Excel 내보내기 제한** | SE16N에서 MATDOC/BKPF 등 대형 테이블 조회 시 XML-EXPORT만 가능. Excel 직접 내보내기 불가 |
| **ALV Grid — 셀 병합 불가** | 확장된 ALV 뷰에서 고정/비고정 열 간 병합 표시 안됨. 정보 가독성 저하 |
| **OLE Automation — 불가능** | SAP ↔ Excel/Word 자동 연동 전무. BAPI/Report 기반 Office 문서 생성 시 WebGUI에서 동작 안함 |

### 중위험 (작업 효율성 저하)

| 제한 | S/4HANA 영향 시나리오 |
|---|---|
| **키보드 네비게이션 제한** | FP02/FB50 등高频 트랜잭션에서 화살표 키로 필드 이동 불가. 데이터 입력 속도 대폭 저하 |
| **스크롤 위치 유지 미지원** | ME23N 구매주문서 등 긴 화면에서 스크롤 위치 유실. 검토 작업 시 반복 스크롤 필요 |
| **StepLoop 스크롤 미지원** | 커스텀 Z 프로그램이나 레거시 트랜잭션에서 문제 발생 |
| **Dropdown Listbox 제한** | ALV/TableControl에서 첫 글자 입력으로 빠른 선택 불가. Alt-ArrowDown 필수 |
| **Tree Control 제한** | SE16N/SE80 등 객체 트리 탐색 시 키보드/드래그 앤 드롭 불가. 마우스 휠도 특정 영역에서만 동작 |
| **TextEdit Control 제한** | ME21N/FB50 등 메모/비고 입력 시 워드랩 문제, 보호 영역 미지원 |

### 저위험 (S/4HANA에서는 영향 적음)

| 제한 | 이유 |
|---|---|
| **Business Graphics** | S/4HANA는 분석을 Fiori/Analytics로 이관. WebGUI에서 그래픽 보는 경우 적음 |
| **IMC 미지원** | S/4HANA에서 IMC 사용 사례 극히 제한적 |
| **Microsoft RemoteApp** | 별도 인프라 이슈. S/4HANA와 직접 관련 낮음 |
| **프론트엔드 프린팅 (PDF만)** | 인쇄가 PDF로 출력되는 점은 기능상 문제없음. 다만 레이아웃 제어 제한 |
| **ABAP List 스크롤** | S/4HANA에서 LIST 출력보다 ALV/Fiori 선호 |
| **SAPscript Editor** | S/4HANA는 Forms/Fiori로 대체 추세 |
| **Clipboard (Block Selection)** | Ctrl-C로 복사 가능하므로 기능상 문제는 없음 |
| **Negative Values 정렬** | 미관상 이슈. 기능상 영향 없음 |
| **Dialog Box Container 모달** | 팝업 동작 차이. 업무 차단은 아님 |
| **HTML Control 제한** | S/4HANA에서 HTML 컨트롤 사용 사례 적음 |

---

### S/4HANA + WebGUI 사용 시 주요 리스크

1. **Excel 연동 차단** — Office Integration 읽기 전용 + ALV Excel 내보내기 제한으로 데이터 분석/수정 워크플로우에 가장 큰 영향
2. **데이터 입력 효율 저하** — 키보드 네비게이션 제한으로高频 트랜잭션(FB50, ME21N 등)에서 작업 속도 현저히 감소
3. **대량 데이터 처리 제한** — ALV 범위 선택 불가 + XML-EXPORT만 가능으로 SE16N 등 데이터 조회·추출 작업에 제약
4. **Fiori 대체 가능 항목 많음** — Business Graphics, SAPscript, ABAP List 등은 S/4HANA에서 Fiori로 대체된 항목이므로 실제 영향 적음

**결론:** S/4HANA를 WebGUI로 사용할 경우 **Excel 연동**과 **데이터 입력 효율**이 가장 큰 병목. 분석/리포팅 작업은 Fiori를, 백오피스 트랜잭션은 네이티브 SAP GUI를 사용하는 것이 권장됩니다.
