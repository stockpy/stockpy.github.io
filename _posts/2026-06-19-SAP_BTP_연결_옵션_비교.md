# SAP BTP 연결 옵션 비교 정리

---

## 1. Private Link (SAP Private Link Service)

| 항목 | 내용 |
|---|---|
| 개요 | SAP BTP ↔ 고객사 IaaS(Azure/AWS/GCP) 계정 내 서비스 간 사설 엔드포인트 연결 |
| 환경 | Cloud Foundry |
| 지원 IaaS | Azure (Private Link), AWS (PrivateLink), GCP (Private Service Connect) |
| 트래픽 | 하이퍼스케일러 백본 네트워크 내부만 경유 (퍼블릭 인터넷 미경유) |
| 주요 시나리오 | BTP 애플리케이션 → Azure/AWS 내 VM(RDS, S/4HANA 등) 사설 접근 |
| 방향 | 양방향 (BTP → IaaS, IaaS → BTP) |
| 장점 | 퍼블릭 IP 노출 없음, 공격 표면 최소화, 설정 비교적 간단 |
| 단점 | 동일 하이퍼스케일러 내에서만 작동, on-premise 연결 불가 |

---

## 2. VPC Connection (VPC Peering)

| 항목 | 내용 |
|---|---|
| 개요 | 고객사 VPC ↔ SAP BTP VPC 간 VPC 피어링을 통한 사설 네트워크 연결 |
| 환경 | 동일 하이퍼스케일러, 동일/크로스 리전 |
| 지원 IaaS | AWS (VPC Peering / Transit Gateway), Azure (VNet Peering) |
| 트래픽 | 하이퍼스케일러 사설 네트워크 |
| 주요 시나리오 | RISE with SAP VPC ↔ BTP VPC 간 사설 통신, 크로스 리전 BTP 서비스 연결 |
| 방향 | 양방향 |
| 장점 | VPC 간 라우팅, 대역폭/지연 시간 우수, IP 기반 접근 제어 |
| 단점 | CIDR 겹침 불가, 동일 클라우드/리전 제한, 네트워크 관리 복잡도 높음 |

---

## 3. Direct Connection (SAP Connectivity Service + Cloud Connector)

| 항목 | 내용 |
|---|---|
| 개요 | SAP BTP ↔ On-Premise 시스템 간 Cloud Connector를 통한 암호화된 터널 (Reverse Proxy 방식) |
| 환경 | Cloud Foundry, Kyma |
| 구성 요소 | Connectivity Service + Destination Service + Cloud Connector (로컬 설치) |
| 트래픽 | BTP → Cloud Connector 암호화된 터널 (퍼블릭 인터넷 상단 TLS) |
| 주요 시나리오 | BTP 앱 → On-Premise SAP/비-SAP 시스템 접근 |
| 방향 | 단방향 (BTP → On-Premise, Reverse Invoke 방식) |
| 장점 | 온프레미스 방화벽 설정 불필요, 설정 간편 |
| 단점 | On-Premise → BTP 방향 호출 불가, Cloud Connector 유지 관리 필요 |

---

## 4. Site-to-Site VPN

| 항목 | 내용 |
|---|---|
| 개요 | On-Premise 네트워크 ↔ SAP BTP/RISE 간 IPsec VPN 터널 구축 |
| 환경 | 온프레미스 ↔ 클라우드 (RISE 환경에서 주로 사용) |
| 구성 요소 | VPN 게이트웨이, IPsec 터널, 라우팅 구성 |
| 트래픽 | 퍼블릭 인터넷 상단 IPsec 암호화 터널 |
| 주요 시나리오 | On-Premise → BTP/RISE 양방향 통신 |
| 방향 | 양방향 |
| 장점 | 양방향 통신, 온프레미스 ↔ 클라우드 네트워크 확장 |
| 단점 | 인터넷 기반 (지연/대역폭 변동), IPsec 관리 복잡, 퍼블릭 인터넷 의존 |

---

## 종합 비교

| 기준 | Private Link | VPC Connection | Direct Conn. | Site-to-Site VPN |
|---|---|---|---|---|
| 연결 대상 | BTP ↔ IaaS 서비스 | BTP VPC ↔ 고객 VPC | BTP ↔ On-Premise | On-Prem ↔ BTP/RISE |
| 트래픽 경로 | 하이퍼스케일러 사설망 | 하이퍼스케일러 사설망 | 인터넷 상단 TLS | 인터넷 상단 IPsec |
| 퍼블릭 인터넷 | ✗ | ✗ | ○ (TLS 암호화) | ○ (IPsec 암호화) |
| 통신 방향 | 양방향 | 양방향 | 단방향 | 양방향 |
| 보안 수준 | 높음 | 높음 | 중간 | 중간 |
| 설정 복잡도 | 중간 | 높음 | 낮음 | 높음 |
| 주요 용도 | 클라우드 간 사설 연결 | VPC 확장/통합 | 온프레미스 접근 | 온프레미스 ↔ 클라우드 |

---

## 선택 가이드

| 시나리오 | 권장 옵션 |
|---|---|
| BTP → Azure/AWS 내 서비스 사설 접근 | **Private Link** |
| BTP VPC ↔ 고객사 VPC 통합 | **VPC Connection** (Peering / Transit Gateway) |
| BTP 앱 → On-Premise 시스템 접근 | **Direct Connection** (Cloud Connector) |
| On-Premise → BTP 양방향 통신 | **Site-to-Site VPN** (또는 전용선) |
